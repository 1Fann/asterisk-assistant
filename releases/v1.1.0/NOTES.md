# asterisk-assistant v1.1.0

## 中文

独立服务器自动检查：可配置 1–1440 分钟，默认 5 分钟；支持立即检查、上次结果和手动停止保护。服务器监护只管理 Asterisk，不再负责 Shizuku 或网关。

下载 `Asterisk-Assistant-1.1.0.apk`，可以覆盖升级相同签名的旧版。附件还提供对应源码和 SHA256SUMS。不含手机账号、密码或签名私钥。

两个助手的 Root 检查任务独立于界面，清理最近任务后仍能检查；深度休眠可能延后检查，恢复也不能证明实际通话音质。已验证范围和已知限制见 README / VALIDATION 或 CHANGES。

## English

Independent Asterisk monitoring, configurable 1–1440 minutes (default 5), immediate checks and manual-stop protection. Gateway recovery is owned by the separate helper.

Download `Asterisk-Assistant-1.1.0.apk` to update an installation with the matching signature. Corresponding source and SHA256SUMS are attached. No device accounts, passwords or signing keys are included. See the repository's validation notes for tested scope and remaining device/call checks.
