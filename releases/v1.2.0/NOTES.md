# asterisk-assistant 1.2.0

内置 AGI 空姓名号码分段修复；跨 Root 管理器部署；公网 IPv6 Wi-Fi 接收锁及可关闭的 Android 11–13 息屏兼容，替代迁移时的外置补丁。

Bundled AGI missing-name formatting fix, portable root-provider support, IPv6 Wi-Fi receive locks and optional Android 11–13 screen-off compatibility.

首次使用需本人确认 Root、Shizuku 和系统权限，并在手机本地配置账号。详见 NEW-PHONE-SETUP.md。没有上传私人配置或签名密钥。

First use requires user-approved permissions and local account setup. No private configuration or signing key is included.
